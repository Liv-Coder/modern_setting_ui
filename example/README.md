# Modern Settings UI Example

This example demonstrates how to use the Modern Settings UI package in a Flutter application.

## Features Demonstrated

- Basic settings screen with multiple sections
- Switch settings items (Dark Mode, Notifications)
- Dropdown settings items (Language selection)
- Material 3 theming
- State management for settings values

## Getting Started

1. Make sure you have Flutter installed and configured
2. Navigate to the example directory:

   ```bash
   cd example
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the app:

   ```bash
   flutter run
   ```

## Code Structure

- `lib/main.dart` - Main application with settings screen implementation
- `pubspec.yaml` - Dependencies for the example app

## Usage

The example shows a simple settings screen with:

- **Appearance section**: Dark mode toggle
- **General section**: Language selection and notifications toggle

Each setting demonstrates how to handle state changes and update the UI accordingly.
